# CiscoPacketTracerLab


## Om dette repoet

Hovedmålet med denne labben er å øve på nettverkoppsett ved hjelp av Cisco Packet Tracer. Teste forskjellige nettverksoppsett og konfigurere Cisco-enheter.

Målet er å få bedre forståelse for hvordan nettverk fungerer i praksis, og lære hvordan man setter opp, konfigurerer og feilsøker nettverk.

## Liste på prosjektene:

1. [Peer to Peer](projects/peer-to-peer.pkt)
2. [LAN-Hub](projects/LAN-Hub-Network.pkt)
3. [LAN-Switch](projects/LAN-Switch-Network.pkt)



## Mål

Målet med prosjektet er å bli bedre kjent med Cisco-produkter, lære mer om nettverk og få praktisk erfaring med å realisere forskjellige nettverksoppsett gjennom simulering.
